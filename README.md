# Employee Management System

## 📌 Project Overview
The Employee Management System is a full-stack web application developed to manage employee information efficiently. It allows users to perform CRUD (Create, Read, Update, Delete) operations on employee records.

## 🚀 Features
- Add new employee details
- View all employee records
- Update employee information
- Delete employee records
- Store and manage employee data in a database

## 🛠️ Technologies Used
**Frontend:** React.js

**Backend:** Java, Spring Boot

**Database:** MySQL

**Tools:** Eclipse IDE, VS Code, Postman, Git, GitHub

## ⚙️ CRUD Operations
- **Create:** Add new employee records.
- **Read:** Retrieve and display employee details.
- **Update:** Modify existing employee information.
- **Delete:** Remove employee records.

## 🎯 Project Objective
To develop a full-stack web application that simplifies employee data management using React, Spring Boot, and MySQL.
